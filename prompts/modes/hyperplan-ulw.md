# Mode: hyperplan + ultrawork

Hyperplan first, then ultrawork. Do not skip the planning gate.

1. Run the five hyperplan lanes over the current draft or the goal.
2. Fix every blocker in the plan.
3. Obtain approval if the plan changes user-visible behavior or scope.
4. Enter ultrawork and execute the approved plan.
5. Verify with dual evidence and an independent review before completion.

If the plan is already approved and unchanged, proceed directly to ultrawork.
If a lane reports a blocker that requires an owner decision, stop and ask.
